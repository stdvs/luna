# LUNA — Lunar Site Intelligence & Mission Readiness Navigator

**NASA Space Apps Challenge 2026**

A polished, scientifically grounded, AI-assisted lunar landing-site analysis web application.

---

## Overview

LUNA enables mission planners and researchers to evaluate candidate lunar landing sites, assess solar illumination profiles and Earth communication windows, perform multi-site comparative trade studies, and generate mission reports with strict data provenance.
